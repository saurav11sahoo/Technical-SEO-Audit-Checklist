
# Internal Linking Audit Checklist

Internal linking connects pages within the same website and helps users and search engines discover relevant content.

A structured internal linking strategy improves content discoverability, supports website navigation, and helps search engines understand relationships between pages.

## 1. Internal Link Discovery

- [ ] Crawl the website to identify internal links.
- [ ] Identify pages with very few incoming internal links.
- [ ] Find orphan pages that have no discoverable internal links.
- [ ] Identify important pages that are difficult to reach.
- [ ] Review internal links across navigation, breadcrumbs, and page content.
- [ ] Identify pages receiving links from irrelevant or unrelated content.

## 2. Anchor Text Analysis

- [ ] Review anchor text for clarity and relevance.
- [ ] Use descriptive anchor text that explains the destination.
- [ ] Identify generic anchors such as "click here" where more descriptive text would help.
- [ ] Check for excessive repetition of exact-match keyword anchors.
- [ ] Review whether the surrounding content supports the destination link.
- [ ] Avoid misleading or keyword-stuffed anchor text.

## 3. Internal Link Opportunities

- [ ] Identify relevant contextual linking opportunities.
- [ ] Link supporting blog content to relevant service or category pages.
- [ ] Connect related articles within the same topic cluster.
- [ ] Add links to important resources where they genuinely help readers.
- [ ] Review newly published content for relevant existing pages to link to.
- [ ] Check whether important commercial pages receive appropriate contextual links.

## 4. Broken and Redirected Internal Links

- [ ] Identify internal links returning 404 errors.
- [ ] Investigate internal links returning 5xx errors.
- [ ] Identify links pointing to redirected URLs.
- [ ] Replace outdated destinations with relevant working URLs.
- [ ] Check for redirect chains and unnecessary redirects.
- [ ] Verify that updated links point to the intended final destination.

## 5. Link Placement and Page Structure

- [ ] Review contextual links within the main page content.
- [ ] Check navigation and footer links.
- [ ] Review breadcrumb links where applicable.
- [ ] Ensure links are accessible and understandable.
- [ ] Avoid adding links where they disrupt readability.
- [ ] Check whether important links are accessible on mobile devices.

## 6. Internal Linking and Content Architecture

- [ ] Review links between pillar pages and supporting articles.
- [ ] Check relationships between parent and child pages.
- [ ] Connect related resources through meaningful contextual links.
- [ ] Identify important pages with insufficient internal link support.
- [ ] Review links between related service pages.
- [ ] Ensure internal linking supports the intended website hierarchy.

## 7. Link Attributes and URL Consistency

- [ ] Review unexpected nofollow attributes on internal links.
- [ ] Check whether important internal links use the preferred canonical URL.
- [ ] Verify that links use consistent HTTPS URLs.
- [ ] Check for links to non-indexable pages where an alternative exists.
- [ ] Review JavaScript-generated links where crawlability may be affected.

## 8. Prioritisation and Validation

- [ ] Prioritise important pages with weak internal link support.
- [ ] Assess the relevance and usefulness of proposed links.
- [ ] Document recommended link additions and corrections.
- [ ] Record affected source and destination URLs.
- [ ] Re-crawl the website after implementation.
- [ ] Verify that new links are accessible and lead to the correct destinations.

## Recommended Tools

- Screaming Frog SEO Spider
- Sitebulb
- Google Search Console
- Google Sheets or Excel
- Website analytics platforms

## Audit Recommendations

Internal linking improvements should be based on page relevance, website structure, user needs, and the importance of destination pages.

Avoid adding links solely to increase link counts or repeating exact-match keyword anchors unnaturally.

The objective is to create meaningful connections between related pages and make important information easier to discover.

## Validation

After implementing changes, crawl the website again to review incoming internal links, broken destinations, redirecting links, anchor text, and page accessibility.

This checklist is a starting point for a website-specific internal linking audit.
