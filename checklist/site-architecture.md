# Website Architecture Audit Checklist

Website architecture defines how pages are organised, connected, and accessed by visitors and search engines.

A well-structured website makes important content easier to discover and helps search engines understand relationships between pages.

## 1. Website Hierarchy

- [ ] Review the overall website hierarchy.
- [ ] Check whether categories and subcategories follow a logical structure.
- [ ] Ensure important landing pages have appropriate positions in the hierarchy.
- [ ] Identify unnecessarily deep page structures.
- [ ] Review whether similar topics are grouped logically.
- [ ] Check for overlapping or competing category pages.

## 2. URL Structure

- [ ] Review URL patterns across the website.
- [ ] Ensure URLs are descriptive and understandable.
- [ ] Check for unnecessary URL parameters.
- [ ] Maintain consistent URL formatting.
- [ ] Identify duplicate URLs.
- [ ] Review unnecessary folders or URL depth.
- [ ] Check for broken or outdated URL structures.

## 3. Navigation

- [ ] Review primary navigation menus.
- [ ] Check whether important pages are accessible through navigation.
- [ ] Review dropdown and mega-menu functionality.
- [ ] Check mobile navigation.
- [ ] Ensure navigation links point to the correct destinations.
- [ ] Identify unnecessary navigation complexity.

## 4. Internal Page Relationships

- [ ] Review links between parent and child pages.
- [ ] Check contextual links between related pages.
- [ ] Ensure important service and category pages receive relevant internal links.
- [ ] Identify orphan pages.
- [ ] Review links between related content clusters.
- [ ] Check whether navigation reflects the website's actual hierarchy.

## 5. Breadcrumb Navigation

- [ ] Check breadcrumb implementation on relevant pages.
- [ ] Verify that breadcrumb paths reflect the actual website hierarchy.
- [ ] Ensure breadcrumb links work correctly.
- [ ] Check consistency between visible breadcrumbs and structured data where implemented.
- [ ] Avoid misleading breadcrumb hierarchies.

## 6. Pagination and Faceted Navigation

- [ ] Review pagination on category and listing pages.
- [ ] Check whether paginated pages are accessible.
- [ ] Identify unnecessary combinations of filter parameters.
- [ ] Review duplicate URLs generated by sorting and filtering.
- [ ] Ensure internal links support the intended discovery of content.

## 7. Orphan and Deep Pages

- [ ] Identify pages without incoming internal links.
- [ ] Review important pages located too deep within the site.
- [ ] Add relevant internal links where appropriate.
- [ ] Evaluate whether important content should be moved closer to relevant navigation paths.

## 8. Mobile and User Experience

- [ ] Review navigation on mobile devices.
- [ ] Check menu accessibility and usability.
- [ ] Verify that important content remains accessible.
- [ ] Check for broken navigation elements.
- [ ] Review whether users can easily reach key pages.

## Recommended Tools

- Screaming Frog SEO Spider
- Google Search Console
- Sitebulb
- Browser developer tools
- Website analytics platforms

## Audit Recommendations

Prioritise architecture changes according to their effect on important page discovery, crawlability, user navigation, and content relationships.

Avoid changing established URL structures without assessing redirects, internal links, canonical signals, and existing search visibility.

## Validation

After changes, crawl the website again and review URL hierarchy, internal link paths, orphan pages, navigation accessibility, and affected page status codes.

This checklist provides a starting point for a website-specific architecture audit.
