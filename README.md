
# Technical SEO Audit Checklist

A practical technical SEO audit checklist for website owners, SEO professionals, and digital marketers.

This resource covers the essential areas of technical SEO, including crawlability, indexation, website architecture, internal linking, canonicalisation, and website performance.

## About This Project

Technical SEO helps search engines discover, crawl, understand, and index website content.

This checklist provides a structured approach to identifying technical issues and documenting opportunities for improvement.

1. Crawlability

- [ ] Check whether important website pages can be crawled.
- [ ] Review the robots.txt file for unintended crawling restrictions.
- [ ] Identify broken internal links and HTTP 4xx errors.
- [ ] Identify server errors (5xx).
- [ ] Check for unnecessary redirect chains.
- [ ] Verify that important pages are accessible through internal links.

2. Indexation

- [ ] Review indexed pages in Google Search Console.
- [ ] Check pages blocked by noindex directives.
- [ ] Verify canonical tags on important URLs.
- [ ] Review XML sitemap coverage.
- [ ] Identify duplicate or near-duplicate pages.
- [ ] Investigate important pages excluded from Google's index.
- [ ] Verify that XML sitemaps contain canonical, indexable URLs.

3. Website Architecture

- [ ] Review the website's URL structure.
- [ ] Check whether important pages are accessible within a reasonable number of clicks.
- [ ] Identify orphan pages.
- [ ] Review category and subcategory structures.
- [ ] Check breadcrumb implementation.
- [ ] Ensure that important pages receive relevant internal links.

4. Internal Linking

- [ ] Identify broken internal links.
- [ ] Review links pointing to redirected URLs.
- [ ] Identify important pages with insufficient internal links.
- [ ] Review internal anchor text for relevance.
- [ ] Check for excessive links that do not provide navigation value.
- [ ] Ensure important content is discoverable through contextual links.

5. Canonicalisation and Redirects

- [ ] Check canonical tags for important pages.
- [ ] Identify conflicting canonical signals.
- [ ] Review HTTP and HTTPS versions.
- [ ] Verify preferred www or non-www versions.
- [ ] Check trailing slash consistency.
- [ ] Identify redirect loops and unnecessary redirect chains.
- [ ] Ensure redirected URLs point to relevant destinations.

6. On-Page Technical Elements

- [ ] Review page titles for duplication and relevance.
- [ ] Check meta descriptions.
- [ ] Review H1 headings and heading structure.
- [ ] Check image alt attributes where appropriate.
- [ ] Verify mobile rendering.
- [ ] Review structured data where applicable.
- [ ] Validate structured data against visible page content.

7. Website Performance

- [ ] Review Core Web Vitals field data.
- [ ] Check Largest Contentful Paint (LCP).
- [ ] Check Interaction to Next Paint (INP).
- [ ] Check Cumulative Layout Shift (CLS).
- [ ] Review image optimisation.
- [ ] Identify unnecessary JavaScript and CSS.
- [ ] Check mobile page performance.

8. HTTPS and Website Security

- [ ] Verify HTTPS implementation.
- [ ] Identify mixed-content issues.
- [ ] Check HTTP-to-HTTPS redirects.
- [ ] Verify that canonical URLs use the preferred protocol.

 Recommended Audit Tools

- Google Search Console
- Google PageSpeed Insights
- Screaming Frog SEO Spider
- Google Rich Results Test
- Chrome Lighthouse

 How to Use This Checklist

1. Start with a website crawl.
2. Review crawlability and indexation issues.
3. Examine website architecture and internal linking.
4. Investigate technical errors and performance issues.
5. Document findings and supporting evidence.
6. Prioritise fixes based on impact, severity, and implementation effort.
7. Re-crawl the website to validate completed fixes.

 Important Note

This checklist is a practical starting point, not a substitute for a website-specific technical SEO audit. Findings should always be validated using available crawl data, search performance data, and manual inspection.
