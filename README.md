
# Technical SEO Audit Checklist

A practical technical SEO resource library for website owners, SEO professionals, and digital marketers.

This project brings together structured audit checklists and practical templates to help identify, document, prioritise, and resolve technical SEO issues.

## Audit Checklists

| Resource | Description |
|---|---|
| [Crawlability Audit](checklist/crawlability.md) | Review crawling accessibility, robots.txt, HTTP status codes, and crawl paths. |
| [Indexation Audit](checklist/indexation.md) | Investigate indexing issues, canonicalisation, and sitemap coverage. |
| [Website Architecture Audit](checklist/site-architecture.md) | Evaluate website hierarchy, navigation, URL structure, and page relationships. |
| [Internal Linking Audit](checklist/internal-linking.md) | Identify internal linking opportunities, broken links, and anchor text issues. |
| [Website Performance Audit](checklist/performance.md) | Review Core Web Vitals, loading performance, and technical optimisations. |

## How to Use This Resource

1. Crawl the website using an SEO auditing tool.
2. Select the relevant checklist for the identified issue.
3. Document findings in the audit tracker.
4. Prioritise issues based on their severity and impact.
5. Implement the recommended fixes.
6. Re-crawl and validate the improvements.
